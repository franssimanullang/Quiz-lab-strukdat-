<br> Penjelasan soal nomor 3<br>
Program ini menggunakan representasi Adjacency Matrix dua dimensi berukuran $6 \times 6$ untuk memetakan hubungan antar vertex lokasi kampus (A hingga F) beserta bobot jaraknya, serta mengimplementasikan algoritma BFS dan DFS untuk penelusuran graf serta algoritma Dijkstra untuk menghitung jalur terpendek dan melacak rute lintasan secara akurat berdasarkan input interaktif dari pengguna. <br>

<br>Alur Program<br>
Alur program dimulai dengan menginisialisasi matriks dengan bobot jarak sesuai tabel, menampilkan representasi matriks graf ke layar, menjalankan penelusuran BFS dan DFS dari titik awal yang ditentukan, lalu meminta masukan vertex awal dan tujuan secara dinamis dari pengguna untuk diproses oleh algoritma Dijkstra guna menampilkan total jarak terpendek beserta rute lengkap yang harus dilalui.
